## 1. PCA (Principal Component Analysis) — самый популярный
PCA ищет новые признаки, сохраняющие максимум информации.
Пример: 100 признаков → 10 компонент ≈ 95% информации.

Под капотом (грубо):
1) анализирует взаимосвязи признаков;
2) находит направления, где данные меняются сильнее всего;
3) проецирует данные на эти направления.
Математика: ковариационная матрица + собственные векторы.

Применение: уменьшение размерности; ускорение; борьба с мультиколлинеарностью; визуализация.
Минус: PC1, PC2, PC3 плохо интерпретируемы.

Когда применять: много признаков; сильные корреляции; долгий fit; модели чувствительны к размерности/корреляции (линейные, SVM, KNN). Деревья/бустинг — реже.
Когда НЕ: 10–20 понятных признаков; нужна интерпретируемость; деревья и так ок.
PCA не смотрит на y — только на структуру X. Может даже ухудшить предсказание.

Перед PCA почти всегда StandardScaler (разные масштабы age/salary).

explained_variance_ratio_: доля дисперсии по компонентам; можно n_components=0.95.

Утечка: fit PCA только на train, transform на test. Лучше Pipeline(Scaler, PCA, Model).
CV: PCA внутри каждого фолда. Подбор n_components — GridSearchCV / по дисперсии + CV.

## 2. LDA (Linear Discriminant Analysis)
Часто путают с PCA. PCA только X. LDA: X+y, строит оси, где классы максимально разделены.
Применение: снижение размерности перед классификацией; иногда как классификатор.
Шаги: межклассовая дисперсия Sb, внутриклассовая Sw, найти проекцию max разделимости.

## 3. NCA (Neighbourhood Components Analysis)
Преобразует пространство так, чтобы объекты одного класса стали ближе (для KNN).
Использует метки y. Реже, чем PCA/LDA. Практически с KNN.

## 4. t-SNE
Задача — визуализация (2D/3D), не обучение модели.
Сохраняет соседство точек из высокой размерности. Не для feature pipeline обучения.

## Сравнение
| Метод | Использует y | Главная цель |
| PCA | нет | max информация/дисперсия |
| LDA | да | max разделение классов |
| t-SNE | нет (для обучения) | красивая визуализация |
| NCA | да | соседи одного класса ближе |
